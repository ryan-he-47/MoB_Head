## 5. 诚实边界（写 README 时的口径）

1. **SmolLM2 的词表只有 49k**（Llama 128k 的 0.38×）：原生侧带宽/算力同比缩小，头级优势在 GPU 上被 kernel-launch 开销吃掉（batch 1 平价、batch 256 多层头更慢）。**MoB 的效率故事随词表放大**：Llama 线（128k 词表 + 32M 头）头带宽 −75~86%、CPU 头 12.9×、CPU 端到端 +29~31%（docs/08）。本轮数据应表述为"49k 词表下头带宽 2-3.2×、CPU 头 1.8-3.0×、GPU 端到端平价"，而不是夸大。
2. roundflip/自适应重排的 e2e 开销是 Python 循环实现的工件；round 提议路径才是效率模式（0.25ms）。
3. 保真数字全部 vs SmolLM2 原生头自归一化；与 Llama 线的横比受词表/难度混杂，不作叙事。
4. 32M control 在 SmolLM2 上 50k 步即饱和（2.40×）——容量约束签名；50M 新架构未到硬顶（末 30k 仍有 +0.08pt/10k 缓爬）。
