## 任务 1：已评审论文清单（精选，按 相关性 × 经典性 × SOTA 三要素）

> 从 docs/18/19/23 三轮调研的 ~80 篇中精选 11 篇。分层逻辑：**奠基必读**（缺了会被评审直接挑战）、**SOTA 竞品划界**（2024-2026，定义了本文的对比坐标）、**相邻范式**（防止被归入已有赛道）。

### A. 奠基必读（经典 + 最高相关）

| # | 论文 | 出处 | 为什么必读 |
|---|---|---|---|
| A1 | **Oda et al., "Neural Machine Translation via Binary Code Prediction"** | ACL 2017, arXiv:1704.06918 | **最近邻**：首个"词表 token → 二进制码 → 逐位 sigmoid 预测"的工作。其核心结论"裸二进制预测脆弱、必须靠 ECC"恰好反向印证本项目"混合 + 语义码免 ECC"的设计动机。写作时既要致敬也要划清六点差异（docs/18 §3 表格） |
| A2 | **Yang et al., "Breaking the Softmax Bottleneck: A High-Rank RNN Language Model" (MoS)** | ICLR 2018, arXiv:1711.03953 | **混合输出头**的概念先例 + softmax 秩受限理论奠基。MoB 头 = 把 MoS 的"K 个 V 维 softmax 分量"换成"K 个 17 位因子化伯努利分量"，一句话即可定位继承关系 |
| A3 | **Lample et al., "Large Memory Layers with Product Keys"** | NeurIPS 2019, arXiv:1907.05242 | **因子化次线性访问**思想的经典先例：query 切半 → 子键集 top-k → 笛卡尔积 = 超大键空间的精确检索。与本项目"语义码结构"同属"用码结构换访问效率"谱系，且证明了大查表结构可与 transformer 端到端共训（支撑轴 B 叙事） |
| A4 | **Grave et al., "Efficient Softmax Approximation for GPUs" (adaptive softmax)** | ICML 2017, arXiv:1609.04309 | 频率聚类 shortlist 谱系的代表，连同 Morin & Bengio 2005 分层 softmax 构成"静态结构化输出空间"的完整谱系——本项目是对这条 20 年谱系的"学习式 + 语义极小码"升级 |

### B. SOTA / 竞品划界（2023-2026，定义对比坐标）

| # | 论文 | 出处 | 划界要点 |
|---|---|---|---|
| B1 | **Zhou et al., "DistillSpec"** | ICLR 2024, arXiv:2310.08461 | "蒸馏小网络当提议器 + 目标模型验证"的奠基工作（SD 加速 10-45%）。是赛道 B 必须显式引用的最近邻：MoB 级联与它的差异 = 提议**逐位置候选集**而非串行 token 序列、重排用**同模型原头 gather** 而非额外验证前向 |
| B2 | **Li et al., "EAGLE-3"** | NeurIPS 2025, arXiv:2503.01840 | 投机解码 SOTA（batch1 端到端 ~2.9×，batch≥32 失效）。定位：正交可叠加的乘法关系，非竞品；同时其每个 draft 头都是 h×V 投影，反证 h×V 带宽问题 |
| B3 | **FlashHead** | arXiv:2603.14591, 2026 | **最强应用竞品**：免训练、即插即用、1.75× 端到端、零质量损失。本项目在纯加速指标上打不过它，价值锚点必须落在"候选集精确密度 + 码即接口 + 可原生预训练"（docs/18 §5.2 弱点 1 的应对） |
| B4 | **BitLM** | arXiv:2605.11577, 2026-05 | **概念正上方邻居**：同样论证"大词表 softmax 是历史选择"，同样用二进制超立方体；但机制（扩散头 vs 蒸馏伯努利混合）、目标（块内多 token 并行 vs 单 token 分布）、训练（从头 vs 冻结骨干蒸馏）全不同，且无归一化密度、无加速现有模型能力 |
| B5 | **LLaDA（+ Dream / Mercury / Gemini Diffusion / DiffusionGemma）** | arXiv:2502.09992 / 2505.14831, 2025-2026 | **扩散式 LM 家族**（docs/23 G1，本轮最大缺口）：与 MoB 在最高层竞争同一目标（逃离自回归 softmax 串行瓶颈），但整范式替换（多步并行去噪、每步仍是 V 维 softmax、需重训、质量暂逊 AR）vs 只换输出表示（单步 AR 兼容、drop-in 蒸馏）。工业界已承认 lm_head 是可替换部件（DiffusionGemma），反而抬升本命题热度 |

## 任务 2：新增两篇综述论文（近五年，与课题直接相关）

### 综述一：Efficient Large Language Models: A Survey（Wan et al., arXiv:2312.03863，TMLR 2024）

- **覆盖**：模型级效率技术的全景分类——量化（PTQ/QAT）、剪枝、蒸馏、低秩分解、MoE/稀疏激活、架构改造、推理加速、系统设计，附效率评估方法论讨论。
- **与本课题的相关点**：其"架构级效率 vs 压缩级效率"的二分正是本项目两轴的学术语境——MoB 头同时横跨两者（蒸馏 = 压缩级落地；原生预训练 = 架构级主张）。综述确认了一个事实：**现有架构级效率工作几乎只改 trunk（MoE、线性注意力、GQA），lm_head 被视为固定部件**——本项目的空白点正是从这里来。
- **引用价值**：intro 用其建立"efficient LLM"大框架，再把 MoB 头定位在综述分类的空格里。

### 综述二：A Survey on Efficient Inference for Large Language Models（Zhou et al., arXiv:2404.14294，2024）

- **覆盖**：数据级 / 模型级 / 系统级三层优化框架，含实测对比实验（量化、speculative decoding、serving 系统的横向 benchmark），是推理效率领域引用最广的综述之一。
- **与本课题的相关点**：其"模型级 → 解码算法（SD 家族）→ 输出层"的拆解里，输出层一节只覆盖自适应/分层 softmax 与采样近似（2024 年中的快照），**检索式头（FlashHead/CSV）与码结构头（BitLM/MoB）都是这之后的 2025-2026 新物种**——正好用来论证"输出层效率是 2025 年后才重新活跃的前沿"，本课题踩在窗口上。
- **引用价值**：related work 的效率大框架 + "解码是内存带宽受限"的定量依据（其系统级分析）。

> 备选（若导师要求更多）：Xia et al., "Unlocking Efficiency in LLM Inference: A Comprehensive Survey of Speculative Decoding"（ACL 2024 Findings, arXiv:2401.07851，docs/18 已收录）；Zhu et al., "A Survey on Model Compression for LLMs"（TACL 2024）。

## 任务 3：近五年（2021-2026）关键进展总结（基于上述综述 + 三轮竞品调研）

**主题一：优化目标从"算力"转向"内存带宽与串行步数"。** 2021-2022 年的主流是训练后压缩（剪枝/量化/SVD，模型更小但推理结构不变）。2022 年底投机解码（Leviathan, arXiv:2211.17192；Chen, arXiv:2302.01318）首次系统性地攻击**串行性**；随后业界认清 decode 阶段是 memory-bandwidth-bound（Kipply 2022 公式进入教科书），优化矛头转向**每步权重带宽**。本项目（头带宽 -75~86%、CPU 步 12.9×）属于这一转变的"输出层"分支——两篇综述均把该分支列为开放问题。

**主题二：输出层从"黑箱 softmax"变成可设计的部件。** 谱系：分层/自适应 softmax（2005-2017，静态树/频率簇）→ MoS/秩瓶颈理论（2018，表达能力）→ kNN-LM（2020，检索插值）→ 2025-2026 爆发：VQ-Logits（码本+scatter）、CSV-Decode（可证明裁剪）、FlashHead/HNSW（免训练检索）、BitLM（二进制码+扩散头）、DiffusionGemma（工业界把 AR 头换成扩散头）。**五年前的综述里输出层只有一节静态内容，现在已成独立赛道**——窗口确证。

**主题三：方法学分野——"免训练即插即用" vs "蒸馏/重训换结构"。** FlashHead/CSV/HNSW 证明免训练路线能把 top-k 做到零损失；BitNet/dLLM 证明重训路线能换掉整个表示。**本课题的差异化 = 两派之间唯一的中间态**：蒸馏成本远低于重训（25.3 V100 小时，docs/09），却换来了免训练路线没有的东西（归一化密度、码接口、可预训练性、VRAM 释放）。

**主题四：提议-验证（propose-verify）成为通用架构模式。** 2023：SD（draft LM 提议、目标模型验证）；2024：DistillSpec（蒸馏对齐提议器）、Medusa/EAGLE（多头提议）；2025：AdaSPEC（选择性蒸馏）、S2T（跨模型提议-重排）；2026：S2T-Local。**MoB 级联 = 该模式在"候选集"粒度上的新实例**（逐位置平面候选 + gather 精确重排），且提议器自带码结构——这是该模式五年演进中尚未被占据的位置。

**主题五：二值/离散表示的复兴。** 权重侧：BitNet→BitNet b1.58（2023-2024，CPU 原生推理成立）。表示侧：语义 ID（TIGER 2023）→ LFQ/单码本视觉 tokenizer（2024）→ 二进制码生成（BitDance/BitLM/MultiHashFormer, 2026）→ 输入侧二进制嵌入（Bochkov 2026）。本项目的语义超立方体码是"表示侧二进制化"在 **LM 输出层**上的落点，且是该谱系中唯一带"邻近 = 语义近"布局与学习式混合密度的工作。

## 任务 4：研究进度摘要（Current Progress）

### 4.1 一句话

把 LLM 的解嵌层（h×V matmul + V 维 softmax）蒸馏为一个 32 分量 × 17 位因子化伯努利混合（MoB）头，词表经语义二叉树映射到超立方体顶点；目标是"一个可证明近似无损推理优化、可原生预训练、带可编程码接口的新输出表示范式"。

### 4.2 两条验证轴 + 当前成绩（全部为实测；Llama 3.2 1B = 主线口径，SmolLM2 = 架构赛马口径）

> **叙事口径（用户定调 2026-09-15）**：性能汇报以 **Llama 3.2 1B（V=128,256）为主线**——大词表才是 h×V 瓶颈的真实战场，效率与保真的主数字全部出自此线（docs/08/09）；**SmolLM2（V=49,152）线的价值在"实验更全面"**（三头结构赛马 + 全套基准 + 提议策略复评），但其词表只有 Llama 的 0.38×，效率数字天然缩水（头带宽 2-3.2×↓、GPU 端到端平价），且其更好看的一致率/召回不可与 Llama 线横比（任务难度被小词表稀释，docs/20 §5 已声明）——**汇报时讲机制结论，不把 SmolLM2 的绝对数字当 headline**。

**SmolLM2 线补充（docs/20，机制结论为主）**：三头赛马（228k 步同数据同基座）证明**头结构是显著变量**——SwiGLU 49.3M 归一化 PPL **1.78×** / 一致率 0.805 vs 控制 MLP 31.9M 的 2.41× / 0.761（ResMLP 1.90× 居中）；好头上自适应解码反超 roundflip（0.981 vs 0.973 召回），兑现"自适应成绩是头校准质量下界"的预言；49k 词表下头带宽仅 2-3.2×↓、GPU 端到端平价——**再次确认效率叙事属于大词表**。

### 4.3 效率成绩的边界条件（docs/08/20 实测）

- **效率收益随词表放大**（核心边界条件）：128k 词表（Llama）是真实战场——头带宽 −75~86%、CPU 数量级加速；49k 词表（SmolLM2）下头带宽仅 2-3.2×↓、GPU 端到端平价（kernel-launch 开销吃掉优势）。项目效率主张锚定大词表端侧模型（Llama-3.2/Gemma-2-2B 类，head 占参数 15-45%，docs/18 §4.3）。
- **offload 是范式 novelty 的价值证明**（docs/19 §2）：llama.cpp 证明"只把 lm_head 丢 CPU 不缩候选" = 500ms/token 慢路径；级联把输出侧变成 32 行小 gather 后 CPU 整步仅 6.42ms，lm_head 常驻 CPU 才首次可行，省 ~464 MiB 显存。

### 4.4 已排除/已关闭的分支（诚实记录）

- 骨干联合微调（P4）：LoRA r32 与全量解冻最后 4 层都收敛到同一 ~3.23 nats 盆地（相对冻结头 3.29 仅 -2%）——"低秩适配不适合重塑输出几何"的用户判断被证实；full-rank 泛化更好。
- 编码器侧 MLP（docs/10）：不可行，项目范围锁定解码器侧。
- 头规模双轨（宽 4096 vs 深 3072×5）：+59% 参数无收益（宽轨）；函数类探针证线性臂 -27pt（浅层探针饱和签名）。

### 4.5 未达项与下一步

1. **验收里程碑未达**：目标"归一化 PPL 显著优于 2× + 生成语义正确"——主线（Llama-3.2-1B，128k 词表）当前 **2.00×**，压线；SmolLM2 线的 1.78× 因小词表不可横比（见 §4.2 叙事口径），不作为里程碑证据。级联口径的有效保真（重排 93.8% / roundflip 96.5%，生成 PPL 2.02 vs 原生 2.35）已达"近似无损推理优化"的成立标准，全分布密度口径是剩余差距。
2. 下一步队列：① 赛马头上的自适应解码复评（校准依赖分数是头质量下界，已证伪担忧方向——好头上自适应反超 roundflip）；② from-birth 蒸馏（教师软标签 + 原生 MoB 学生，管线愿景的关键缺失实验，建议 P5）；③ 语义树 vs 随机码 vs id 码消融 + Oda 式"单伯努利+ECC"对照臂（把"免 ECC"从主张变成实测）；④ 双胞胎扩 scale 确立折扣斜率。
3. 投稿准备（docs/18/23）：定位"候选提议器 + 原头精确重排 + 码接口"三合一；四线 related work 防守（FlashHead 加速线 / BitLM+dLLM 范式线 / DistillSpec 提议器线 / Oda-ECOC 位码线）已盘点完毕，参考论文清单见本文件任务 1。
